# Validation figures

Cell-by-cell comparison of this Python port to the Fortran BCM Daily
source on the Mokelumne River watershed (270 m, Sierra Nevada,
California), 26 Dec 1996–3 Jan 1997.

- `domain_pack.png` — elevation and nine-day mean snowpack
- `pck_scatter.png` — Fortran vs Python snowpack (1:1)
- `rmse_bars.png` — RMSE by variable
- `spatial_snow.png` — nine-day mean pack and melt (Fortran, Python, difference)
- `spatial_flow.png` — nine-day mean recharge and runoff (Fortran, Python, difference)
